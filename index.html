1快速上手

1打开软件，左栏默认已有 B1（绿色）和 B2（红色）两个据点
2左栏据点列表点一下要操作的据点（选中后高亮）
3右栏点「GTI占领」等示例按钮，自动填好事件链
4点「▶ 运行事件链」，中间据点播放占领动画
5满意了点「🎬 导出视频」，存成 MP4（或带透明的 WebM）
第一次用建议按这个顺序看：第 3 章（背景）→ 第 6 章（事件链规则）→ 第 8 章（颜色规则）→ 第 10 章（导出）。这四章看完基本就不会踩坑了。

2界面风格

在 设置 → 界面风格 切换，默认经典版：

风格布局适合人群
经典版左侧控制台 + 中间预览习惯集中操作
节点版三栏 + 底部节点编辑器需要可视化拖拽编排
节点版的板块边缘可以拖动调整大小。
节点版提示：事件积木可以拖到画布任意位置（包括下面很远处），连线会跟着延长， 画布会自动出现滚动条，不会被裁掉。拖完想回到左上角，直接滚动即可。

3背景切换

纯白 #FFFFFF
抠像 #990066

左栏顶部两个按钮一键切换。快捷键 Ctrl+1 纯白 / Ctrl+2 抠像。

抠像色 #990066 与据点所有颜色不重叠，录屏后可在剪辑软件中一键抠除。
提示：背景色不只是屏幕底色，导出时「半透明灰块」透出来的也是它。 所以想要白色底片就选纯白，想要后期抠像就选抠像。

4据点管理

操作方法限制
创建左栏输入名称 → 点创建或回车最多 6 个
选择左栏据点列表点一下一次只能选一个运行
删除据点右边红色 ×运行中不能删
附属据点输入名称前勾选「附属据点（图标显示）」不支持大事件
附属据点：据点中央不是文字，而是一个「方形底座 + 旗子」的图标。 图标取自官方素材的高清图，颜色跟着阵营走（GTI 绿 / HAVVK 红 / 中立白）。 绿色后退时同样是「图标 ↔ 感叹号」来回闪，中断保留进度、导出视频这些表现和普通据点一致。

注意：附属据点不支持大事件（变种 1~4 都不行）——大事件要改名、倒塌、替换文字， 而附属据点中央是图标、没有文字层。选中附属据点时「添加事件」下拉里的大事件会变灰， 硬把大事件塞进链里再运行会报 [E014]。
提示：附属据点的图标大小跟着「设置 → 据点大小」一起变，不需要单独调。

5三种编辑模式

5.1 代码模式

右栏代码框直接写 JSON，适合需要灵活修改的人。

示例：GTI占领
[
  {"type":"redState"},
  {"type":"redRetreat","duration":3},
  {"type":"standby","duration":0.5},
  {"type":"greenAdvance","duration":3}
]
  • 美化缩进：一键整理 JSON 格式
  • 参数说明：展开所有积木的完整写法
  • 示例链：点下方标签一键填充
JSON 写错会报 [E304]，日志里会指出出错的位置。注意别用中文引号、别多写逗号。

5.2 可视化模式

经典版下的表单式编辑，不用写代码：

  1. 顶部下拉选择事件类型（greenState / redAdvance / bigEvent 等）
  2. 下方自动出现对应参数输入框（duration、variant 等），直接填数字
  3. 点「添加到列表」，事件出现在下方列表
  4. 列表里每个事件可以上移 / 下移 / 删除调整顺序
  5. 大事件会展开更多参数（变种选择、白色推进时间、倒塌延时等）
可视化模式和代码模式实时同步，改哪边另一边都跟着变。
提示：必填参数带 *，没填会标红；事件类型下面那行小字就是中文说明， 不确定选哪个就照着读一遍。

5.3 节点编辑器（节点版）

节点版底部的拖拽式编排区：

  1. 顶部下拉「+ 添加事件」选择积木类型
  2. 节点出现在画布上，拖头部移动位置，自动连线
  3. 点节点下方参数区域展开输入框，改完点保存
  4. 点节点右上角 × 删除
节点顺序 = 从左到右、从上到下的执行顺序，拖乱了顺序执行顺序也会变，排好再运行。

6事件链基础

事件链 = 一串积木，按顺序执行，上一个跑完才跑下一个。

链首规则：第一个积木必须是 greenState / redState / neutralState，否则报错 [E002]。
跨色规则：绿色推进完不能直接接红色，必须先 greenRetreat 清空边框，否则报错 [E004] / [E005]。
大事件规则：单条链最多 1 个大事件，否则报错 [E008]。
中断规则：interrupt 必须紧跟在 advance / retreat 后面，并保证 triggerAt 小于前一个动画的 duration，否则报错 [E101] / [E102]。
提示：不确定链对不对，先点运行看日志。所有校验错误都会在开头就报出来，不会跑到一半才崩。

7事件积木大全

积木参数说明
greenState无完整绿色据点（仅链首）
redState无完整红色据点（仅链首）
neutralState无中立据点（无边框白字，仅链首）
greenAdvanceduration绿色边框顺时针推进
redAdvanceduration红色边框顺时针推进
greenRetreatduration绿色边框逆时针消退（连带警报闪烁）
redRetreatduration红色边框逆时针消退
standbyduration保持当前状态等待 N 秒
interrupttriggerAt依附前一个动画，N 秒后强制中断保留进度
bigEventvariant + ...大事件，见第 9 章
duration 单位是秒，可以写小数（0.5 = 半秒）。数值越大动画越慢。
中断示例怎么看出效果：用「中断」示例链跑一遍——中立起步 → 推进 7 秒 → 第 3 秒时被中断， 边框停在 43% 左右，文字保持白色，然后 standby 2 秒，再后退 4 秒回到中立。

8颜色与状态规则

这一章是「为什么颜色跟我预期不一样」的答案，建议看完。

8.1 已有阵营的据点继续推进

边框和文字立刻就是阵营色（绿推进绿字、红推进红字），不再先白后变色。被中断、暂停也保持阵营色。

8.2 中立据点被占领

外框直接显示阵营色并带进度，但名称全程白色；只有进度走满 100% 的那一刻， 文字才变成绿 / 红。中途被中断，文字依然是白色。
占领到一半又退回来：文字继续白色，并且不触发警报闪烁（据点本来就没丢，不算被反推）。 退完回到纯中立的白点。

8.3 后退与警报闪烁

绿色后退时，只要边框还有进度（不用满格），名称就会和感叹号「↔」来回闪。 被中断、或者链跑完了，闪烁都继续，直到下一次推进或清空据点。 想手动停掉：点「强制停止」。

8.4 脉冲闪光

只有边框闭合完成（占领成功）才闪一下脉冲。正常跑完不会把闪光掐掉，只有强制停止才会清掉。
提示：这些颜色规则在预览和导出视频里是完全一致的，不用担心中间出现两边不一样的情况。

9大事件（bigEvent）

变种 1 · 炸毁变中立

{"type":"bigEvent","variant":1,"whiteDuration":2.5}

白色边框包围 → 名称 / × 交替闪烁 → 变中立

变种 2 · 自动归属 GTI

{"type":"bigEvent","variant":2,"whiteDuration":2.5,"greenDuration":2.5}

白色包围后直接长绿色边框 → 归属 GTI，触发绿光脉冲

变种 3 · 替换敌方据点

{"type":"bigEvent","variant":3,"whiteDuration":2.5,"oldName":"尖塔","newName":"废墟","collapseDelay":2}

白色包围后等待倒塌延时 → 直接变红色据点，名称替换，无脉冲。倒塌延时填 0 = 没有延时，边框一闭合就立刻换成新名称

变种 4 · 护送车队

两套模式（在 设置 → 实验性功能 里切）：默认是旧版——只有「初始时间 / 变红倒计时」（加阵营和名称）， 固定 3 个检查点、坦克匀速走完全程、倒计时归零就结束；切到新版才有下面这些参数。 两版的颜色、名称、导出效果完全一样。

{"type":"bigEvent","variant":4,"totalSeconds":270, "checkpoints":[{"remain":180,"bonus":45},{"remain":135,"bonus":45},{"remain":60,"bonus":0}], "tankStates":[{"seg":1,"at":10,"state":"repair"},{"seg":2,"at":0,"state":"arrow2"}], "failMode":"none","failValue":0,"holdSeconds":2,"warningAt":10}

隐藏其他据点，显示护送 UI（进度条 + 检查点 + 旗子 + 坦克 + 倒计时）。

  • totalSeconds：初始时间，270 = 4 分 30 秒
  • checkpoints：每行两个格子——走到该点时剩几秒 / 到点加几秒。 最后一行是撤离点（不加时）。每段耗时 = 上一点加时后的剩余 − 本点剩余， 所以「什么时候到撤离点」是你填出来的，坦克状态不会影响它。 撤离点填 剩 0 是「掐着 0 秒到达」＝卡点成功； 要中途耗尽用下面的 failMode
  • tankStates：坦克前方的小图标时间轴，每行「第几段 / 段内第几秒 / 图标」。 段号照检查点下面那张分段表填（1 = 起点到第 1 个检查点），改检查点不用重算。 none 无图标（正常速度）、arrow1/2/3 单/双/三箭头加速、 repair 修理（停住）、warn 感叹号（几乎停）。图标只影响段内位移，段末自动追平， 所以加速或停顿都不会改变到点时间
  • ⚠ 冲突提示：段号写超、段内秒超过这一段时长（永远不生效）、 两条挤在同一秒、状态排在时间归零之后……列表下面会直接出现 ⚠ 提示， 每条都写明「怎么改」，照着改就行
  • failMode / failValue：none 正常到撤离点； checkpoint + 序号＝到达第 N 个检查点时耗尽； route + 百分比＝走到该进度时耗尽（这一段会被自动拉长到刚好归零）
  • holdSeconds：归零后定格几秒再结束录制，默认 2
附属据点不能跑大事件（报 [E014]）。护送（变种 4）在普通背景下也能跑； 导出前要先在页面上运行一次，否则素材没加载会报 [E306]。 导出时 MP4 自动铺纯紫幕 #990066（和页面录屏同一个抠像色，色度键抠除），WebM 自动出透明背景。

10导出视频

点「🎬 导出视频」（快捷键 Ctrl+E），自动渲染动画并编码保存。默认导出 MP4。

10.1 两种格式怎么选

格式特点用在哪儿
MP4（H.264，默认）标准封装，PR / 剪映 / 达芬奇 / 手机相册都能直接导入，不卡顿、有缩略图直接发视频、导入剪辑软件
WebM（VP9）唯一支持透明通道，但部分软件导入不友好需要叠在别的画面上做透明素材
MP4 没有透明通道。选 MP4 时如果又把「据点灰色背景」设成透明，只会得到黑色背景， 所以需要透明素材请务必切到 WebM。

10.2 画面构成

模式分辨率背景
据点模式512 / 768 / 1024 正方形铺满整帧，没有外圈留白，边框贴着画面边缘
护送模式960×440（自动取偶数，H.264 要求）MP4 = 纯紫幕 #990066（和页面录屏同色，色度键抠除）；WebM = 透明背景
据点模式下画面就是据点本身，四周不会有额外的黑边 / 灰边。 脉冲闪光是「边框变粗 + 向内发光」，贴着画面边缘也看得见。

10.3 保存与进度

  1. 导出时弹出进度窗，点「—」可最小化为右下角悬浮圆窗，点圆窗恢复
  2. 编码完成会弹系统「另存为」对话框，自己选位置（会记住上次的目录）
  3. 保存成功后进度窗自动收起，结果写在左下角日志：格式、分辨率、时长、帧数、大小、完整路径
  4. 想找文件：点日志里那行「📂 打开所在文件夹」
提示：如果日志提示「实际采样 xx fps（设定 60fps）」，说明本机编码跟不上， 画面会略卡。降低分辨率 / 帧率，或改用 MP4，通常就能跑满。
导出期间请勿关闭窗口，也不要切走太久（后台会掉帧）。

11事件模板

做好的事件链可以导出保存，下次直接导入：

  • 导出模板：点「📤 导出模板」，下载 .deltaTemplate 文件
  • 导入模板：点「📥 导入模板」，选择文件自动加载
模板只是一份事件链配置，不包含据点设置和颜色，换台电脑导入后仍是同样的动作。

12设置面板

分组设置项说明
导出视频格式MP4（默认，最兼容）/ WebM（带透明通道）
分辨率512 / 768 / 1024，越大越清晰、文件越大
帧率60 fps（流畅）/ 30 fps（更省资源）
码率10 Mbps 推荐；20 更清晰；5 文件更小
据点灰色背景保留灰块 / 透明（仅 WebM 生效）
显示据点大小预览区据点尺寸，160~320px，带重置
灰块透明度0~100%，界面和导出同步，带重置

提示：所有设置自动保存在本机，下次打开还是上次的配置。 调乱了就用每项右边的「重置」按钮，只重置那一项。

14报错代码速查

所有报错带 [Exxx] 编号：

代码段类别常见原因
E001-E014校验错误链首不对、跨色没清空、大事件参数缺失、附属据点跑大事件
E101-E102中断错误interrupt 位置不对 / triggerAt 超过前一个动画时长
E205-E210据点错误没选据点、据点满了、名字重复
E301-E305导出前置错误没选据点、链正在跑、节点编辑器或可视化列表为空、JSON 写错
E306护送素材未加载先在页面上运行一次护送车队，再导出
E307不支持录制系统异常，重启软件试试
E308不支持 MP4 编码去设置把格式切成 WebM
E309保存失败目标目录没权限 / 磁盘满了 / 同名文件被占用
E310编码失败分辨率异常或编码器异常，换 512 分辨率重试
E401-E405模板错误模板格式不对、校验失败
E0xx 基本都是事件链写得不对，按提示改积木顺序或参数。

15常见问题

Q：点运行没反应？
A：看左栏日志框，红色报错就是事件链不对。没报错就确认选了目标据点。

Q：能多个据点同时动吗？
A：设计是一次一个，其他静止。跑完一个再选另一个。

Q：动画速度怎么调？
A：每个 advance / retreat 的 duration 就是时长（秒），越大越慢。

Q：可视化模式在哪？
A：经典版右栏，代码框上方有「代码 / 可视化」切换按钮。

Q：节点编辑器参数怎么改？
A：点节点下方参数区域，展开输入框改完点保存。

Q：从中立据点开始占领，为什么名字还是白的？
A：这是设计如此——外框已经在走进度，但只有占满 100% 才算占领，文字那一刻才变色。详见第 8 章。

Q：后退的警报闪烁怎么停不下来？
A：只要边框还有进度就会一直闪，这是提醒「据点正在丢」。点「强制停止」手动复位。

Q：导出的视频有一圈黑边？
A：现在不会有外圈了，画面铺满整帧、边框贴着边缘。如果看到黑边，确认用的不是旧版本。

Q：导出视频据点背景能透明吗？
A：设置 → 格式选 WebM，据点灰色背景选「透明」。MP4 不支持透明。

Q：导出完成找不到文件？
A：日志里有完整路径，点那行「📂 打开所在文件夹」即可。

Q：导出的视频有点卡？
A：日志会给出实际采样帧率。降低分辨率或帧率、改用 MP4，基本能跑满。
